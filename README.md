# RaceDay System

A full-stack web-based event management system designed for the South African road running, walking, and cycling community.

## Part 1: System Planning and Database

This repository contains the planning and database design documents for the RaceDay system.

### System Overview

The RaceDay platform aims to modernize the management of road events, connecting Event Organisers and Participants. It will allow for event creation, management, participant enrolment, and result tracking.

### Key Features (Planned)

- **User Management:** Role-based access for Organisers and Participants.
- **Event Management:** Organisers can create, update, and manage events.
- **Category Management:** Events have different categories (e.g., age groups, gender).
- **Enrolments:** Participants can enrol in events and pay entry fees.
- **Results:** Organisers can publish results for participants.

### Database Design

The database consists of 8 main entities: Roles, Users, Organisers, Participants, Events, Categories, EventEnrolments, and Results. The design supports a clear separation of roles and a comprehensive event lifecycle.

### Technologies Used (Planned)

- **Database:** Microsoft SQL Server
- **Backend:** .NET Core / Node.js (Choose one for Part 2)
- **CI/CD:** GitHub Actions
